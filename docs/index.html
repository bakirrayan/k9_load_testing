⚡ one engine, four ways in

Write it like k6. Run it on Rust.

script.py 
import k9

options = {
    "vus": 50,
    "duration": "1m",
    "thresholds": {"http_req_duration": ["p(95)<300"]},
}

async def default():
    res = await k9.http.get("https://test.k6.io/")
    k9.check(res, {"status is 200": lambda r: r.status == 200})
options:
  vus: 10
  duration: 30s
  thresholds: { http_req_failed: ["rate<0.01"] }
flows:
  default:
    - request:
        method: POST
        url: https://example.com/login
        body: '{"user": "{{ users.name }}"}'
        extract: { token: { json: $.token } }
    - request:
        url: https://example.com/me
        headers: { Authorization: 'Bearer {{ token }}' }
        checks: { ok: { status: 200 } }
import k9.plan as p

token = p.var("token")

# Python builds the plan once; the run has no Python in it.
plan = p.Plan(
    [
        p.post("https://example.com/login", json={"user": "bob"},
               extract={"token": p.from_json("$.token")}),
        p.get("https://example.com/me",
              headers={"Authorization": f"Bearer {token}"},
              checks={"ok": p.status(200)}),
    ],
    options={"vus": 10, "duration": "30s"},
)
import pytest

# Crossed thresholds fail the test.
@pytest.mark.k9("load/smoke.py", vus=10, duration="30s")
def test_checkout_holds_up(k9_result):
    assert k9_result.metric("http_req_duration")["p(95)"] < 300

def test_two_runs(k9_run):
    assert k9_run("load/a.yaml").ok and k9_run("load/b.yaml").ok

✦ three tiers

Python where it helps. Rust where it counts.

k9 inspect tells you which tier a test runs in, so you know what it costs before you run it.

1
Declarative

YAML plans and k9.plan

Python builds the plan once, before the run. Templates, extractors and feeders keep data flowing with no Python in the hot path.

Python in the hot path
None: full Rust speed
2
Hooks

setup, vu_init, teardown

Log in once per VU, prepare data, write your own summary with handle_summary. Each runs once, so its cost doesn't grow with the load.

Python in the hot path
Negligible
3
Iteration functions

async def default()

Full Python on every iteration: thousands of async VUs on one event loop, or plain def on a thread per VU, across cores with --workers.

Python in the hot path
Every iteration; scale with workers

⚡ from install to first run

Your first load test is three commands away.

Install the wheel (Linux, macOS, Windows; no Rust needed), let k9 new write the test, and point it at your service.

terminal 
$ pip install k9-load                       # or: uv tool install k9-load
$ k9 new --url http://localhost:3000/health # a starter script.py
$ k9 run script.py -u 5 -d 10s
